# Rafiq Al Manasik — External Resources

This repository documents the external libraries and services used by the Rafiq Al Manasik project.

## Flutter Dependencies
- flutter_tts — Text-to-speech accessibility.
- url_launcher — External links and Google Maps.
- shared_preferences — Local settings and language preferences.
- image_picker — Camera and image selection.
- google_mlkit_text_recognition — Text recognition.
- speech_to_text — Speech recognition.
- http — Communication with the PHP API.
- easy_localization — Localization support.

## External Services
- Google Maps — Maps and directions.
- Google Translate — External translation for signs.
- HelioHost — PHP and database hosting.

## Project Repositories
- Flutter application: rafiq-almanasik-flutter-final
- Website: rafiq-almanasik-website-final
- Database schema: rafiq-almanasik-database-final

Dependencies are declared in the Flutter application's pubspec.yaml. This repository does not contain passwords, API keys, or private configuration files.
